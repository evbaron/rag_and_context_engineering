# Selatan

**Selatan** is the [Malay](/wiki/Malay_language) and Indonesian word for [south](/wiki/South) and can be found in topography.
E.g.

- Sulawesi Selatan -> [South Sulawesi](/wiki/South_Sulawesi)
- Sumatera Selatan -> [South Sumatra](/wiki/South_Sumatra)
- [South Cape (Indonesia)](/wiki/South_Cape_(Indonesia))
- Lebuhraya Utara-Selatan -> [North–South Expressway (Malaysia)](/wiki/North%E2%80%93South_Expressway_(Malaysia))
