# Jill Quertier

## Infobox

- **Born:** 1936 (age 89–90) Bromley, Kent, England
- **Occupation:** Set decorator

**Jill Quertier** (born 1936) is an English [set decorator](/wiki/Set_decorator). She won an [Academy Award](/wiki/Academy_Awards) in the category [Best Production Design](/wiki/Academy_Award_for_Best_Production_Design) for the film *[Shakespeare in Love](/wiki/Shakespeare_in_Love)* and was nominated for another for *[Quills](/wiki/Quills_(film))*.

## Selected filmography

- *[Shakespeare in Love](/wiki/Shakespeare_in_Love)* (1998; won with [Martin Childs](/wiki/Martin_Childs))
- *[Quills](/wiki/Quills_(film))* (2000; nominated with [Martin Childs](/wiki/Martin_Childs))
