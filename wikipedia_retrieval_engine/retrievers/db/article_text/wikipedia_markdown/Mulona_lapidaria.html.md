# Mulona lapidaria

***Mulona lapidaria*** is a [moth](/wiki/Moth) of the [subfamily](/wiki/Subfamily) [Arctiinae](/wiki/Arctiinae_(moth)). It was described by [Francis Walker](/wiki/Francis_Walker_(entomologist)) in 1866. It is found on [Haiti](/wiki/Haiti).
