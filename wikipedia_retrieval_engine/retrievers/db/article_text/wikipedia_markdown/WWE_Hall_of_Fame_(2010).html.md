# WWE Hall of Fame (2010)

## Infobox

- **Promotion:** WWE
- **Date:** March 27, 2010
- **City:** Phoenix, Arizona [ 1 ]
- **Venue:** Dodge Theatre

**WWE Hall of Fame (2010)** was the event which featured the introduction of the 11th class to the [WWE Hall of Fame](/wiki/WWE_Hall_of_Fame). The event was produced by [World Wrestling Entertainment](/wiki/WWE) (WWE) on March 27, 2010, from the [Dodge Theatre](/wiki/Arizona_Federal_Theatre) in [Phoenix, Arizona](/wiki/Phoenix,_Arizona). The event took place the same weekend as [WrestleMania XXVI](/wiki/WrestleMania_XXVI). The event was hosted by [Jerry Lawler](/wiki/Jerry_Lawler). A condensed one-hour version of the ceremony aired on the [USA Network](/wiki/USA_Network) that same evening. In March 2015 the ceremony was added to the [WWE Network](/wiki/WWE_Network).
