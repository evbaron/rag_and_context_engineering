# Secret Service code name

President [John F. Kennedy](/wiki/John_F._Kennedy), code name "Lancer", with First Lady [Jacqueline Kennedy](/wiki/Jacqueline_Kennedy), code name "Lace"

The [United States Secret Service](/wiki/United_States_Secret_Service) uses [code names](/wiki/Code_name) for [U.S. presidents](/wiki/President_of_the_United_States), [first ladies](/wiki/First_Lady_of_the_United_States), and other [prominent persons](/wiki/Very_Important_Person) and locations. The use of such names was originally for security purposes and dates to a time when sensitive [electronic communications](/wiki/Telecommunications) were not routinely [encrypted](/wiki/Secure_communication); today, the names simply serve for purposes of brevity, clarity, and tradition. The Secret Service does not choose these names, however. The [White House Communications Agency](/wiki/White_House_Communications_Agency) maintains a list that candidates choose from, often choosing ones that resonate with them personally.

According to an established protocol, good codewords are unambiguous words that can be easily pronounced and readily understood by those who transmit and receive voice messages by radio or telephone regardless of their [native language](/wiki/First_language). Traditionally, all family members' code names start with the same letter.

The code names change over time for security purposes, but are often publicly known. For security, code names are generally picked from a list of such 'good' words, but avoiding the use of common words which could likely be intended to mean their normal definitions.
