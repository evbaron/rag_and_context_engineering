# Kalkbrenner

**Kalkbrenner** ([German](/wiki/German_language): occupational name for a [lime burner](/wiki/Limeburner)) is a German surname. Notable people with the surname include:

- [Christian Kalkbrenner](/wiki/Christian_Kalkbrenner) (1755–1806), German bandmaster
- [Friedrich Kalkbrenner](/wiki/Friedrich_Kalkbrenner) (1785–1849), German pianist
- [Fritz Kalkbrenner](/wiki/Fritz_Kalkbrenner) (born 1981), German musician
- [Paul Kalkbrenner](/wiki/Paul_Kalkbrenner) (born 1977), German musician
- [Ryan Kalkbrenner](/wiki/Ryan_Kalkbrenner) (born 2002), American basketball player
